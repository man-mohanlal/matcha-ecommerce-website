# Failda Matcha — Premium Artisanal Matcha eCommerce Website 🍵

An aesthetic, responsive eCommerce web platform crafted for Failda Matcha, featuring authentic ceremonial grade matcha from Kyoto.

## ✨ Features

- **Home Page (`index.html`)**: Editorial hero section, product highlights, benefits, customer reviews, and newsletter.
- **Products Catalog (`products.html`)**: Product grid with filtering, detailed cards, quick add to cart, and pricing.
- **Process & Craftsmanship (`process.html`)**: Story and timeline of Kyoto shade-grown matcha cultivation, steaming, stone-grinding, and packaging.
- **About Us (`about.html`)**: Brand philosophy, farm origins, master tea blenders, sustainability commitments, and FAQs.
- **Journal / Blog (`blog.html`)**: Editorial tea culture articles, brewing guides, and wellness tips.
- **User Account & Auth (`account.html`)**: Sign-in, registration, and user authentication portal.
- **Profile & Dashboard (`profile.html`)**: User order history, subscription management, address book, and settings.

## 🛠️ Built With

- **HTML5 & Semantic Structure**
- **Tailwind CSS** (via CDN with container-queries & forms plugins)
- **Google Fonts** (*Plus Jakarta Sans*) & **Material Symbols**
- Fully responsive design optimized for mobile, tablet, and desktop

## 🚀 Live Demo & Deployment

This project is built as a static site and can be deployed in seconds with:
- **GitHub Pages** (Built into this repository)
- **Vercel** / **Netlify** / **Cloudflare Pages**

## 💻 Local Preview

Simply open `index.html` in any web browser, or use a local development server:

```bash
# Python 3
python -m http.server 3000

# or Node npx
npx serve .
```

Then visit `http://localhost:3000`.
